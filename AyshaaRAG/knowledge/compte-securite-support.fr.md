## Comment créer un compte client ?

Sur le site XPARK, cliquez sur Espace Client → Inscription. Renseignez votre
nom, prénom, email et mot de passe (8 caractères minimum). Un email de
confirmation avec un code à saisir vous est envoyé — le code expire après
24 heures. Une fois l'email confirmé et le compte approuvé, vous recevez un
email de bienvenue et pouvez vous connecter.

## J'ai oublié mon mot de passe, que faire ?

Sur la page de connexion, cliquez sur « Mot de passe oublié ». Saisissez votre
email : vous recevez un code de réinitialisation valable 1 heure. Entrez ce
code avec votre nouveau mot de passe sur la page de réinitialisation. Si le
code a expiré, refaites simplement une demande.

## Comment sécuriser mon compte (MFA) ?

Espace Client → Sécurité propose la vérification en deux étapes (MFA) avec
deux méthodes : 1) **Application Authenticator** (Google/Microsoft
Authenticator) — un QR code à scanner, puis un code à 6 chiffres qui change
toutes les 30 secondes, la méthode la plus sûre ; 2) **Vérification par
email** — un code à 6 chiffres envoyé à chaque connexion, valable 10 minutes
avec 5 tentatives maximum. Vous pouvez activer ou désactiver chaque méthode
depuis la page Sécurité, et consulter l'historique de vos connexions.

## Comment contacter le support XPARK ?

Trois canaux : 1) **Espace Client → Support** : ouvrez un ticket (sujet,
catégorie Mission / Facturation / Technique / Autre, mission liée optionnelle,
message) — la réponse de notre équipe s'affiche directement dans votre espace
et vous pouvez fermer le ticket quand votre demande est résolue ;
2) **téléphone** : +216 70 000 000 ; 3) **email** : contact@xpark.tn.
Adresse : Zone industrielle, Tunis, Tunisie.

## Quels sont les statuts d'un ticket support ?

Un ticket passe par : Ouvert (créé) → En cours (pris en charge par l'équipe)
→ Résolu (réponse apportée) → Fermé (clôturé par vous ou par l'équipe). Vous
pouvez fermer votre ticket vous-même quand la réponse vous convient.

français, en anglais et en tounsi, par écrit ou par la voix, aux questions

votre dossier, je vous oriente vers le support humain.
